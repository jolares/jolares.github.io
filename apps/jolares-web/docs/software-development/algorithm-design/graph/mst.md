# Minimum Spanning Tree (MST) Problem

A minimum spanning tree (MST), also called a minimum weight spanning tree,
is a subset of the edges of a connected edge-weighted undirected graph, which
connects all vertices together without any cycles, and having the minimum
possible _total edge weight_ (the sum of all the edges' weights)


## Problem definition

- Input: undirected $G = (V, E)$ with weights $w(e)$ for $e \in E$

- Output: the spanning tree (connected subgraph) of $G$ of minimum weight (minimmall size).
   
## MST algorithms

Two popular algorithms to solve the MST problem are:

- Kruskal's algorithm
- Prim's algorithm
