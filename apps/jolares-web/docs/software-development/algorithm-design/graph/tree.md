# Tree

A _Tree_ is a connected, acyclic graph.

## Properties of a tree 

1) A tree with `n` vertices always has `n-1` edges.
2) Exactly _one_ path exists between _any_ pair of vertices in the tree.
3) Any connected graph $ G=(V, E)$ with $ |E| = |v|-1 $ is a tree.
