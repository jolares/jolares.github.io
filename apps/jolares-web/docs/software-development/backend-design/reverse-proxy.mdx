# Reverse Proxy

A reverse proxy changes the identity of a backend service

- Used for stealth
  - Fetch data secretly, while keeping servers hidden from the client.
  - Motigate cyber-attacks and eavesdropping in websites that
    send or receive sensitive data to a backend service.

## Applications

- A reverse proxy can be used together with an _API gateway_ and a _load balancer_ for safer and more
  efficient client-server communication.
